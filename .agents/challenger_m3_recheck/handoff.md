## 2. Logic Chain

1. *From Observation 1 & 2*: In `src/preview.rs`, unquoted sentences containing spaces (like `"create public/index.html"`) are not treated as valid whole paths because `is_plausible_single_path_with_spaces` rejects non-absolute drive/root paths. They are subsequently split into individual tokens, where `"create"` is discarded and `"public/index.html"` is validated as a previewable web path.
2. *From Observation 1 & 2*: Multiple file references separated by commas (like `"create public/index.html, update assets/logo.svg"`) are separated along comma/whitespace boundaries into distinct paths (`public/index.html` and `assets/logo.svg`) rather than concatenated.
3. *From Observation 1 & 2*: Any token containing `"://"` is explicitly rejected by `candidate_path`. As a result, shell commands such as `"curl -s https://example.com/site.html"` yield an empty result, and `previewable_path_from_tool` returns `None`.
4. *From Observation 1, 2, & 4*: Quoted paths with spaces (e.g. `"C:\My Documents\report.html"`) are extracted via `extract_and_mask_quotes` and validated via `is_plausible_single_path_with_spaces`, preserving valid Windows paths while avoiding spurious secondary tokens.
5. *From Observation 3 & 4*: In `src/chat.rs:601`, `show_entry` receives `session.working_dir()`, ensuring that relative preview paths generated during worktree-isolated sessions resolve to the worktree path rather than the project root.
6. *From Observation 5*: All automated test suites (231 tests) and strict clippy checks pass without failure or warning.
